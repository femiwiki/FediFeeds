In scope

Kind Id An item is
category Page id of the category page A page created while it is in the category. Pages added to the category later are not items.
section Page id A section at the page's unit level whose heading path was not in the previous revision. Edits by bots count.

section

The page sets its unit with {{FEDIFEEDSNAME:<name>|section-unit=<n>}}: each heading with this many equals signs is one note. The default is 2, so each == heading == is one note. A heading with more equals signs belongs to the note above it, and a heading with fewer is context for the notes below it.

An item is identified by the page id and its heading path: the texts of the headings above it and its own. The paths of the parent revision and the new revision are compared. Renaming the heading or any heading above it therefore removes one item and adds another.

A path can occur more than once, as when two sections under the same heading have the same title. Paths are then counted: when the new revision has a path more times than the parent, each extra occurrence is a new item, numbered in the order they appeared. An item exists while the page has its path at least as many times as its number.

For example, a log of updates where each day is a section and each update a section in it, both newest first, sets section-unit=3: 

{{FEDIFEEDSNAME:Updates|section|section-unit=3}}
== 19 October ==
=== 14:10 ===
[https://example.org/changes/2 Change 2]
* Updated the search
==== Added ====
* A new page
=== 09:00 ===
[https://example.org/changes/1 Change 1]
== 18 October ==
=== 14:10 ===
[https://example.org/changes/0 Change 0]

Each update is an item, with a path such as "19 October / 14:10". Adding a new day with its first update makes one item, the update, and the day is its context. The 14:10 under 19 October is a different item from the one under 18 October. ==== Added ==== is part of its update's note. Two updates in the same minute make the path "19 October / 14:10" twice, and the second is item number 2 of that path.

Only a save to an existing page is compared. The headings of a page's first revision are not items, because it has no parent revision. A null edit adds nothing, and neither does a revert, which brings back headings that were there before.

Reserved

These names are kept so that later kinds do not collide. None of them is planned.

Kind An item is
category_added A page added to the category, including existing pages and pages categorised by a template
category_file A file added to the category
page An edit to the page
stable A newly reviewed revision of the page (FlaggedRevs)
related An edit to a page the page links to
file A new version of a file
user_new A page created by the user
user_upload A file uploaded by the user
user_achievements A badge the user receives (AchievementBadges)
namespace_new A new page in the namespace; the id is the namespace number
topics A new topic on a talk page (DiscussionTools)
newsletter A new issue of a newsletter (Newsletter)

Never

These would publish something private, or turn a feed into a way to follow a person around: watchlists, notifications, thanks, block and abuse filter logs, CheckUser, the account creation log, and a feed of every edit by one user.
