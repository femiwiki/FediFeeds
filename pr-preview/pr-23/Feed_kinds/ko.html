지금 다루는 종류

종류 id 항목
category 분류 문서의 문서 id 분류에 든 채로 새로 만들어진 문서. 나중에 분류에 들어온 문서는 항목이 아닙니다.
section 문서 id 문서의 단위 수준에 있는 문단 가운데 제목 경로가 이전 판에 없던 것. 봇 편집도 셉니다.

section

문서는 {{FEDIFEEDSNAME:<name>|section-unit=<n>}}로 단위를 정합니다. 등호가 이만큼인 제목 하나하나가 노트 하나입니다. 기본값은 2이므로 == 제목 == 하나가 노트 하나입니다. 등호가 더 많은 제목은 위에 있는 노트에 속하고, 더 적은 제목은 아래 노트들의 맥락이 됩니다.

항목은 문서 id와 제목 경로로 구별합니다. 제목 경로는 위에 있는 제목들의 글자와 자기 제목의 글자입니다. 부모 판과 새 판의 경로를 비교합니다. 따라서 그 제목이나 위에 있는 제목 하나를 바꾸면 항목 하나가 사라지고 다른 하나가 생깁니다.

같은 제목 아래 두 문단의 제목이 같을 때처럼, 경로 하나가 여러 번 나올 수 있습니다. 그러면 경로를 셉니다. 새 판에 어떤 경로가 부모 판보다 많이 나오면 더 나온 것 하나하나가 새 항목이고, 나타난 차례로 번호를 붙입니다. 항목은 문서에 그 경로가 자기 번호만큼 이상 있는 동안 있습니다.

예를 들어 날마다 문단을 두고 그 안에 업데이트마다 문단을 두며, 둘 다 최근 것을 위에 쓰는 업데이트 기록은 section-unit=3을 씁니다. 

{{FEDIFEEDSNAME:업데이트|section|section-unit=3}}
== 10월 19일 ==
=== 14:10 ===
[https://example.org/changes/2 변경 2]
* 검색을 업데이트함
==== 추가 ====
* 새 문서
=== 09:00 ===
[https://example.org/changes/1 변경 1]
== 10월 18일 ==
=== 14:10 ===
[https://example.org/changes/0 변경 0]

업데이트 하나하나가 항목이고, 경로는 "10월 19일 / 14:10" 같은 꼴입니다. 새 날짜를 첫 업데이트와 함께 더하면 항목은 업데이트 하나만 생기고, 날짜는 그 맥락입니다. 10월 19일 아래의 14:10은 10월 18일 아래의 것과 다른 항목입니다. ==== 추가 ====는 그 업데이트 노트의 일부입니다. 같은 분에 업데이트가 두 번 있으면 "10월 19일 / 14:10" 경로가 두 번 나오고, 두 번째는 그 경로의 2번 항목입니다.

이미 있는 문서를 저장할 때만 비교합니다. 문서의 첫 판에는 부모 판이 없으므로 그 제목들은 항목이 아닙니다. 널 편집은 아무것도 더하지 않고, 되돌리기도 마찬가지입니다. 되돌리기는 전에 있던 제목을 되살릴 뿐이기 때문입니다.

예약한 이름

나중에 생길 종류와 겹치지 않도록 남겨 둔 이름들입니다. 만들 계획이 있는 것은 아닙니다.

종류 항목
category_added 분류에 들어온 문서. 원래 있던 문서와 틀을 거쳐 분류된 문서도 포함
category_file 분류에 들어온 파일
page 문서의 편집
stable 새로 검토된 문서 판 (FlaggedRevs)
related 이 문서가 링크하는 문서의 편집
file 파일의 새 판
user_new 사용자가 만든 문서
user_upload 사용자가 올린 파일
user_achievements 사용자가 받은 배지 (AchievementBadges)
namespace_new 이름공간의 새 문서. id는 이름공간 번호
topics 토론 문서의 새 주제 (DiscussionTools)
newsletter 뉴스레터의 새 호 (Newsletter)

만들지 않는 것

아래는 사적인 것을 밖으로 내보내거나, 피드를 특정인을 따라다니는 수단으로 만듭니다. 주시문서 목록, 알림, 감사 표시, 차단 기록과 편집 필터 기록, CheckUser, 계정 생성 기록, 한 사용자의 모든 편집을 담은 피드.
