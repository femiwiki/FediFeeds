# FediFeeds

FediFeeds is a MediaWiki extension that lets people on the Fediverse follow one narrow feed of a wiki,
such as the new posts of a blog kept in a category,
instead of a single account that announces every edit.

The spec comes first and lives on the [documentation site](https://femiwiki.github.io/FediFeeds/),
built from [`docs/`](docs) with [wikven](https://github.com/chaotic-ground/wikven).
Nothing is implemented yet.
